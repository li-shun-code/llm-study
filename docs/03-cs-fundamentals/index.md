# 模块 3 · 计算机基础

后端与 AI 应用共用的底层舞台：Linux 与 Shell、Git 协作、操作系统原理、网络与 HTTP 协议栈。

## 学习路径

**Linux 与 Shell**

- Linux 常用命令：从 Shell 开始
- Shell 脚本入门
- 文件权限
- SSH：远程开发基础

**Git 与持续集成**

- Git 基础：获取仓库、暂存、提交与回退
- Git 分支、合并与远程协作
- Git 进阶：rebase、cherry-pick 与冲突解决
- GitHub Actions 与 CI 基础

**操作系统：进程、线程与并发**

- 操作系统概述：虚拟化、并发与持久化
- 进程：运行中的程序
- 线程：并发导论
- 并发与锁
- 信号与进程间通信 IPC
- CPU 调度：FIFO、SJF、STCF 与轮转

**操作系统：内存与文件系统**

- 内存管理：地址空间抽象
- 虚拟内存：TLB 与地址翻译加速
- 文件系统：文件与目录

**I/O 多路复用与事件循环**

- I/O 多路复用：阻塞、poll() 与 select()
- epoll 与事件循环

**计算机网络**

- 网络分层模型：从 HTTP 请求到 OSI
- DNS：域名系统
- TCP：传输控制协议
- UDP：用户数据报协议
- HTTP 概述
- HTTPS 与 TLS
- SSE 与 WebSocket：流式输出的网络基础
- REST：表述性状态转移（Fielding 论文第 5 章）
