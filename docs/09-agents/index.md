# 模块 9 · Agent 智能体

让模型循环起来：规划、工具与协议、记忆与上下文、编排框架、行动型 Agent 与生产化。

## 学习路径

**奠基：智能体如何思考**

- LLM 驱动的自主智能体（Agent）全景：规划、记忆与工具使用
- ReAct 范式：思考、行动与观察的循环
- 规划与任务分解：构建高效智能体的工作流模式

**工具与协议**

- Tool Use 实战：工具的定义、注入与调用
- Function Calling vs MCP：两代工具接入方式如何取舍
- MCP 协议详解：架构、分层与核心原语（2026-07-28 版规范）
- MCP Server 实战：从零构建一个天气查询服务器
- A2A 协议与跨厂商 Agent 互操作

**记忆与上下文管理**

- Agent 记忆机制：LangGraph 的短期记忆与长期记忆
- 长期记忆系统进阶：Mem0、Letta 与 Zep
- 长时运行 Agent 的上下文管理：压缩（Compaction）

**编排框架**

- LangGraph 入门：用 Graph API 与 Functional API 构建你的第一个智能体
- LangChain 快速入门（1.0 · create_agent）
- 多智能体模式：Anthropic 如何构建多智能体研究系统
- Human-in-the-Loop：用 LangGraph interrupt 实现中断、恢复与人工审批
- AutoGen 与 CrewAI：多智能体框架现状（AutoGen 已并入 Microsoft Agent Framework）
- OpenAI Agents SDK：轻量多智能体框架入门

**行动型 Agent**

- 代码解释器型 Agent：让 LLM 用代码思考（smolagents 与 CodeAct）
- Computer Use 与浏览器操作 Agent：让模型亲手操作图形界面

**生产化：可观测、评测与安全**

- 可观测性与 Tracing：Agent 生产排障的第一工具（LangSmith / Langfuse / OpenTelemetry）
- Agent 评测：数据集、评估器与 LLM-as-Judge 实战
- Agent 安全与权限、生产化部署与成本管理
