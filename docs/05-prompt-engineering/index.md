# 模块 5 · 提示工程与上下文工程

把意图写成模型能稳定执行的指令，并管理好模型每一步能看到的全部信息。

## 学习路径

**提示基础**

- 提示词的基本要素与格式
- 零样本与少样本提示

**推理与任务分解**

- 思维链与多路采样：CoT、Self-Consistency 与失效边界
- ReAct 提示模式：推理与行动交替
- 提示链与任务分解（Prompt Chaining）
- 推理模型时代的提示原则

**系统提示与上下文工程**

- 系统提示词设计
- 上下文工程：为 AI Agent 管理稀缺的注意力

**安全与评估**

- 提示注入：最坏会发生什么？
- 分隔符、结构化标签与注入边界
- LLM-as-Judge 的偏差与校准
- 提示词的迭代与评估方法
