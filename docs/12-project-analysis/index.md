# 模块 12 · 优质项目源码分析

读源码是进阶最快的路径。本模块选取 GitHub 上最火、且在企业中有**实际生产部署价值**的 Agent / LLM 应用开源项目，逐个深入其源码：梳理核心业务流程、解析关键设计决策、精读核心代码实现——让你不只"会用"，更知道"它是怎么写出来的"。

## 本模块项目

| 项目 | 星数 | 语言 | 分析重点 |
|---|---|---|---|
| Dify | ★156K | TypeScript + Python | 工作流执行引擎：节点编排、变量系统、沙箱执行 |
| n8n | ★204K | TypeScript | 节点式自动化平台：任务运行器与执行模型 |
| RAGFlow | ★91K | Go + Python | 企业级 RAG：深度文档理解与检索管线 |
| browser-use | ★115K | Python | 浏览器 Agent：DOM 提取、动作循环与多标签页管理 |

> 本模块文章基于各项目公开源码（clone 自 GitHub main 分支）撰写，代码片段均标注原始文件路径，遵循各项目开源许可。

> 模块内文章基于源码分析撰写，分析视角为本站编者视角；所有代码片段均引自项目仓库并标注路径。
