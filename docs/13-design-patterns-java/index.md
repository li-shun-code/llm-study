# 「Java 设计模式教学专栏」· Java 设计模式教学专栏

设计模式是代码功底的试金石，也是阅读优秀开源项目（包括本站「优质项目源码分析」模块中的 Dify、n8n 等框架）绕不开的基本功。本专栏基于 GitHub 上最著名的 Java 设计模式开源仓库 **iluwatar/java-design-patterns**（★94K+）撰写：每个模式的意图说明译自仓库原文，代码示例均引自仓库的真实 Java 实现（Apache-2.0，代码版权归原仓库作者所有，本专栏为教学性解析并逐篇署名）。

## 专栏篇目

| # | 篇目 | 覆盖模式 |
|---|---|---|
| 01 | 专栏导读与模式总览 | 仓库结构、学习路线、设计模式分类索引 |
| 02 | 创建型模式 | 单例、工厂方法、抽象工厂、建造者、原型、对象池等 |
| 03 | 结构型模式 | 适配器、桥接、组合、装饰器、外观、享元、代理等 |
| 04 | 行为型模式 | 策略、观察者、责任链、命令、模板方法、状态、访问者等 |
| 05 | 企业级架构模式 | Ambassador、Anti-Corruption Layer、Actor Model 等仓库特色企业模式 |

> 教程内容基于 [iluwatar/java-design-patterns](https://github.com/iluwatar/java-design-patterns) 公开仓库（Apache-2.0）撰写，代码示例版权归原仓库作者，逐篇署名出处。
