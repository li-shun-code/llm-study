# 模块 1 · Python 进阶与工程化

写出可维护、可测试、可交付的 Python：语言机制、并发、数据校验、Web 服务与工具链。

## 学习路径

**语言机制进阶**

- 装饰器实战：functools —— 高阶函数与可调用对象上的操作
- 迭代器与生成器（函数式编程指引）
- 上下文管理器：contextlib 完全指南
- 内存管理与垃圾回收：引用计数与 gc 模块
- 类型注解：typing 模块核心章节
- dataclasses 与 NamedTuple：数据类

**并发与异步**

- 并发编程：concurrent.futures 与 threading
- asyncio 异步编程

**文本与数据校验**

- 正则表达式指南（re 模块）
- Pydantic 模型（Models）：数据校验的核心

**HTTP 客户端**

- requests 快速开始与进阶用法
- HTTPX：新一代 Python HTTP 客户端

**Web 服务与应用界面**

- FastAPI 入门与 API Key 鉴权
- FastAPI 进阶：依赖注入、中间件与流式响应
- Gradio 快速开始：为机器学习模型构建演示应用
- Streamlit 入门：基础概念与进阶概念

**工程化与交付**

- Docker 容器化：Python 语言指南
- uv 项目管理：从 uv init 到构建发布（含工程化概念）
- 代码质量工具链：Ruff、mypy 与 pre-commit

**质量与性能**

- pytest 入门与使用指南（Get Started + How-To）
- 日志 logging：HOWTO 与 logging.config
- 性能分析：profile/cProfile 与 py-spy
