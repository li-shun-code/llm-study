## 怎么读

1. **主线**（复杂度 → 线性结构 → 树与堆 → 图 → 查找排序）按顺序读，每篇的代码都应在本机跑一遍。
2. **检索三篇**（Top-K、HNSW、布隆过滤器）是 RAG 的先修算法，读完可以直接衔接模块《向量数据库》与《RAG》。
3. **面试选学三篇**难度最高，建议放最后；`★★★` 以上需要手写代码，`★★☆` 理解思路即可。
4. 需要“这一步标准库有没有现成的”时，直接查《Python 算法工具箱》。
