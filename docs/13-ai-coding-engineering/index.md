# 模块 13 · AI 工程实践与质量安全

把 AI 纳入工程纪律：结对与调试、重构与 TDD、评审与 Git 流程，以及安全、供应链、合规与团队落地。

## 学习路径

**日常开发流**

- 第一次 AI 结对：从零做一个命令行小工具
- Git in AI 工作流：commit 即存档、worktree 隔离与审查流
- 调试 with AI：让 AI 定位 Bug 的工作流
- 重构 with AI：从日常重构到百万行迁移的上下文策略
- TDD with AI：Kent Beck 的增强编程实践
- AI 结对与代码审查

**安全、供应链与合规**

- AI 代码的安全与质量陷阱
- AI 编码供应链安全：幻觉包、Slopsquatting 与沙箱防线
- AI 生成代码的 IP 与合规：版权承诺、责任边界与可版权性

**团队与产品落地**

- 团队落地：AI 编码规范的团队推广与度量
- 从 0 到 1 用 AI 做产品：未来属于能直接动手的人
