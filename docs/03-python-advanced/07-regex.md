## 引言

正则表达式（Regular expressions，也叫 REs、regexs 或 regex patterns），本质上是嵌入 Python 内部并通过 `re` 模块提供的一种微小的、高度专业化的编程语言。使用这种小语言，你可以为想要匹配的可能字符串编写规则；这些字符串可能是英文句子、邮箱地址、TeX 命令或任何你喜欢的内容。然后，你可以提出诸如"此字符串是否与表达式匹配？""字符串中是否存在表达式的匹配项？"之类的问题。你还可以用正则来修改字符串，或以各种方式将其拆分。

正则表达式语言相对较小且受限，因此并非所有可能的字符串处理任务都可以使用正则表达式完成。有些任务尽管**可以**用正则表达式来完成，但表达式会变得非常复杂。这些情况下，最好通过编写 Python 代码来进行处理。也许 Python 代码会比精心设计的正则表达式慢，但它可能更容易理解。

## 简单模式

### 匹配字符

大多数字母和符号都会简单地匹配自身。例如，正则表达式 `test` 将会精确地匹配到 `test`。但该规则有例外。有些字符是特殊的**元字符**，并不匹配自身。这是元字符的完整列表：

```
. ^ $ * + ? { } [ ] \ | ( )
```

首先介绍的元字符是 `[` 和 `]`。这两个元字符用于指定一个字符类，也就是你希望匹配的字符的一个集合。这些字符可以单独地列出，也可以用字符范围来表示（给出两个字符并用 `'-'` 分隔）。例如，`[abc]` 将匹配 `a`、`b`、`c` 之中的任意一个字符；这与 `[a-c]` 相同。如果只想匹配小写字母，则正则表达式将是 `[a-z]`。

元字符（除了 `\`）在字符类中是不起作用的。例如，`[akm$]` 将会匹配 `'a'`、`'k'`、`'m'` 或 `'$'`；`'$'` 通常是一个元字符，但在一个字符类中它的特殊性被消除了。

你可以通过对集合**取反**来匹配字符类中未列出的字符，方法是把 `'^'` 放在字符类的最开头。例如，`[^5]` 将匹配除 `'5'` 之外的任何字符。

也许最重要的元字符是反斜杠 `\`。它用于转义元字符，以便可以在表达式中匹配元字符本身。例如，如果需要匹配一个 `[` 或 `\`，可以在其前面加上一个反斜杠：`\[` 或 `\\`。

一些以 `\` 开头的特殊序列表示预定义的字符集合：

| 特殊序列 | 含义 |
| --- | --- |
| `\d` | 匹配任何十进制数字，等价于字符类 `[0-9]` |
| `\D` | 匹配任何非数字字符，等价于字符类 `[^0-9]` |
| `\s` | 匹配任何空白字符，等价于字符类 `[ \t\n\r\f\v]` |
| `\S` | 匹配任何非空白字符，等价于字符类 `[^ \t\n\r\f\v]` |
| `\w` | 匹配任何字母与数字字符，等价于字符类 `[a-zA-Z0-9_]` |
| `\W` | 匹配任何非字母与数字字符，等价于字符类 `[^a-zA-Z0-9_]` |

这些序列可以包含在字符类中。例如，`[\s,.]` 是一个匹配任何空白字符、`','` 或 `'.'` 的字符类。当正则表达式是 str 类型时，`\w` 将匹配 Unicode 数据库中标记为字母的所有字符（包括中文）；通过提供 `re.ASCII` 标志可以改用较窄的 ASCII 定义。

本节的最后一个元字符是 `.`。它匹配除换行符之外的任何字符，并且有一个可选模式（`re.DOTALL`），在该模式下它甚至可以匹配换行符。

### 重复内容

重复元字符 `*` 指定前一个字符可以匹配零次或更多次。例如，`ca*t` 将匹配 `'ct'`（0 个 `'a'`）、`'cat'`（1 个 `'a'`）、`'caaat'`（3 个 `'a'`）等等。

类似 `*` 这样的重复是**贪婪的**。当重复正则时，匹配引擎将尝试重复尽可能多的次数。如果表达式的后续部分不匹配，则匹配引擎将回退并以较少的重复次数再次尝试。以表达式 `a[bcd]*b` 匹配字符串 `'abcbd'` 为例：引擎先尽可能多地匹配 `[bcd]*` 到字符串末尾，然后尝试匹配结尾的 `b` 失败，就逐步回退少匹配一个字符，最终成功匹配到 `'abcb'`。

另一个重复元字符是 `+`，表示匹配一次或更多次。`*` 与 `+` 之间的差别在于：`*` 允许重复内容完全不出现，而 `+` 要求至少出现一次。`ca+t` 可以匹配 `'cat'` 或 `'caaat'`，但不能匹配 `'ct'`。

问号 `?` 表示匹配一次或零次；你可以认为它把某项内容变成了可选的。例如，`home-?brew` 可以匹配 `'homebrew'` 或 `'home-brew'`。

最复杂的限定符是 `{m,n}`，表示必须至少重复 *m* 次，至多重复 *n* 次。例如，`a/{1,3}b` 将匹配 `'a/b'`、`'a//b'` 和 `'a///b'`，但不能匹配 `'ab'` 或 `'a////b'`。缺失 *m* 会解释为最少重复 0 次，缺失 *n* 则解释为最多重复无限次。最简单情况 `{m}` 将与前一项完全匹配 *m* 次。

三个限定符都可以用此标记法来表示：`{0,}` 等同于 `*`，`{1,}` 等同于 `+`，而 `{0,1}` 等同于 `?`。在可能的情况下使用 `*`、`+` 或 `?` 会更好，因为它们更为简短易读。

## 使用正则表达式

现在我们已经了解了一些简单的正则表达式，那么我们如何在 Python 中实际使用它们呢？`re` 模块提供了正则表达式引擎的接口，可以让你将正则编译为对象，然后用它们来进行匹配。

### 编译正则表达式

正则表达式被编译成模式对象，模式对象具有各种操作的方法，例如搜索模式匹配或执行字符串替换：

```python
>>> import re
>>> p = re.compile('ab*')
>>> p = re.compile('ab*', re.IGNORECASE)  # 可选 flags 参数
```

### 反斜杠灾难

正则表达式使用反斜杠（`'\'`）表示特殊形式，这与 Python 字符串字面量中相同字符的用法相冲突。假设要匹配 LaTeX 中的 `\section`，层层转义后传给 `re.compile()` 的字符串字面量必须写成 `"\\\\section"`——这会导致大量重复的反斜杠，使字符串难以理解。

解决方案是使用 Python 的**原始字符串**表示法：前缀 `'r'` 的字符串中反斜杠不以任何特殊方式处理，因此 `r"\n"` 是一个包含 `'\'` 和 `'n'` 的双字符字符串。正则表达式通常都用原始字符串编写。

| 常规字符串 | 原始字符串 |
| --- | --- |
| `"ab*"` | `r"ab*"` |
| `"\\\\section"` | `r"\\section"` |
| `"\\w+\\s+\\1"` | `r"\w+\s+\1"` |

### 执行匹配

模式对象有几种方法和属性：

| 方法 / 属性 | 目的 |
| --- | --- |
| `match()` | 确定正则是否从字符串的开头匹配 |
| `search()` | 扫描字符串，查找此正则匹配的任何位置 |
| `findall()` | 找到 RE 匹配的所有子字符串，并将它们作为列表返回 |
| `finditer()` | 找到 RE 匹配的所有子字符串，并将它们作为迭代器返回 |

如果没有找到匹配，`match()` 和 `search()` 返回 `None`。如果它们成功，一个**匹配对象**实例将被返回：

```python
>>> import re
>>> p = re.compile('[a-z]+')
>>> print(p.match(""))
None
>>> m = p.match('tempo')
>>> m
<re.Match object; span=(0, 5), match='tempo'>
>>> m.group()
'tempo'
>>> m.start(), m.end()
(0, 5)
```

匹配对象最重要的方法：`group()` 返回正则匹配的字符串，`start()`/`end()` 返回匹配的开始/结束位置，`span()` 返回包含匹配 (start, end) 位置的元组。

## 更多的模式能力

### 零宽度断言与锚点

其余一些元字符是**零宽度断言**。它们不会使解析引擎在字符串中前进一个字符；它们根本不占用任何字符，只是成功或失败。

- `^`：在行的开头匹配。除非设置了 `MULTILINE` 标志，否则只会在字符串的开头匹配。例如 `re.search('^From', 'From Here to Eternity')` 成功，而 `re.search('^From', 'Reciting From Memory')` 返回 `None`。
- `$`：匹配行的末尾，定义为字符串的结尾，或者后跟换行符的任何位置。
- `\b`：字边界，仅在单词的开头或结尾处匹配。例如 `re.compile(r'\bclass\b')` 能匹配 `'no class at all'` 中的 `class`，但不会匹配 `'the declassified algorithm'` 或 `'one subclass is'`。
- `\B`：与 `\b` 相反，仅在当前位置不在字边界时才匹配。
- `\A` / `\Z`：仅匹配字符串的开头/结尾（不受 `MULTILINE` 影响）。

注意 `\b` 是 Python 字符串字面量与正则之间最严重的冲突：字符串字面量里 `\b` 是退格字符（ASCII 8）。不用原始字符串的话，正则就不会按预期工作——又一次，请始终写 `r'\bclass\b'`。

### 分组

正则表达式通常用于通过将正则分成几个子组来解析字符串。分组是用 `'('`、`')'` 元字符来标记的；它们会将所包含的表达式合为一组，并且你可以使用限定符来重复一个分组的内容，举例来说，`(ab)*` 将匹配 `ab` 的零次或多次重复。

组从 0 开始编号（组 0 表示整个正则），子组从左到右从 1 向上编号：

```python
>>> p = re.compile('(a(b)c)d')
>>> m = p.match('abcd')
>>> m.group(0)
'abcd'
>>> m.group(1)
'abc'
>>> m.group(2)
'b'
>>> m.groups()
('abc', 'b')
```

模式中的**后向引用**允许你指定还必须在字符串中的当前位置找到先前捕获组的内容。例如，以下正则检测字符串中重复的单词：

```python
>>> p = re.compile(r'\b(\w+)\s+\1\b')
>>> p.search('Paris in the the spring').group()
'the the'
```

### 非捕获和命名分组

如果只想用组来表示正则的一部分、但不关心其内容，可以用非捕获组 `(?:...)`：

```python
>>> m = re.match("([abc])+", "abc")
>>> m.groups()
('c',)
>>> m = re.match("(?:[abc])+", "abc")
>>> m.groups()
()
```

更重要的功能是**命名组**：`(?P<name>...)`。处理捕获组的匹配对象方法都接受按编号引用组的整数或包含所需组名的字符串：

```python
>>> p = re.compile(r'(?P<word>\b\w+\b)')
>>> m = p.search('(((( Lots of punctuation )))')
>>> m.group('word')
'Lots'
>>> m.group(1)
'Lots'
```

你还可以通过 `groupdict()` 将命名分组提取为一个字典：

```python
>>> m = re.match(r'(?P<first>\w+) (?P<last>\w+)', 'Jane Doe')
>>> m.groupdict()
{'first': 'Jane', 'last': 'Doe'}
```

命名后向引用用 `(?P=name)`：`\b(\w+)\s+\1\b` 也可以写为 `\b(?P<word>\w+)\s+(?P=word)\b`。

### 前视断言

前视断言有肯定型和否定型两种形式：

- `(?=...)`：肯定型前视断言。内部表达式在当前位置可以匹配则成功；但正则引擎并不会向前推进，其余部分依然在断言开始的地方尝试匹配。
- `(?!...)`：否定型前视断言。如果内部表达式在当前位置**不**匹配，则成功。

经典案例：匹配扩展名不是 `bat` 的文件名。用字符类修补的写法会一步步变得无法阅读，而否定型前视一行解决：

```
.*[.](?!bat$)[^.]*$
```

如果有末尾的 `$`，`sample.batch`（只是以 bat 开头）仍会被允许。要再排除 `exe`，只需添加替代：

```
.*[.](?!bat$|exe$)[^.]*$
```

## 修改字符串

正则表达式通常也用于修改字符串，使用以下模式方法：

| 方法 | 目的 |
| --- | --- |
| `split()` | 将字符串拆分为一个列表，在正则匹配的任何地方将其拆分 |
| `sub()` | 找到正则匹配的所有子字符串，并用不同的字符串替换它们 |
| `subn()` | 与 `sub()` 相同，但返回新字符串和替换次数 |

**split()**：在正则匹配的任何地方拆分字符串，比字符串方法 `split()` 更通用。如果在正则中使用捕获括号，则分隔符本身也会作为结果列表的一部分返回：

```python
>>> p = re.compile(r'\W+')
>>> p.split('This is a test, short and sweet, of split().')
['This', 'is', 'a', 'test', 'short', 'and', 'sweet', 'of', 'split', '']
>>> p2 = re.compile(r'(\W+)')
>>> p2.split('This... is a test.')
['This', '... ', 'is', ' ', 'a', ' ', 'test', '.', '']
```

**sub()**：`sub(replacement, string[, count=0])` 返回替换后的字符串。替换串里的后向引用 `\6`、`\g<name>` 会被替换为相应组匹配的子字符串：

```python
>>> p = re.compile('(blue|white|red)')
>>> p.sub('colour', 'blue socks and red shoes')
'colour socks and colour shoes'

>>> p = re.compile('section{ (?P<name> [^}]* ) }', re.VERBOSE)
>>> p.sub(r'subsection{\g<name>}','section{First}')
'subsection{First}'
```

**替换函数**：*replacement* 也可以是一个函数，每次非重叠出现都会调用它、传入匹配对象，用计算结果作为替换串。以下示例将十进制数转换为十六进制：

```python
>>> def hexrepl(match):
...     "返回十进制数字的十六进制字符串"
...     value = int(match.group())
...     return hex(value)
...
>>> p = re.compile(r'\d+')
>>> p.sub(hexrepl, 'Call 65490 for printing, 49152 for user code.')
'Call 0xffd2 for printing, 0xc000 for user code.'
```

## 常见陷阱

- **有时用字符串方法更好**。如果你匹配固定字符串或单个字符类，那么正则表达式的全部功能可能不是必需的。字符串方法通常快得多——`replace()` 能做的事不要用 `re.sub()`；删除单字符用 `translate()` 比任何正则都快。简而言之，在转向 `re` 模块之前，请考虑是否可以使用更快更简单的字符串方法解决问题。
- **贪婪匹配**容易"吃多"，必要时用非贪婪限定符（`*?`、`+?`、`??`、`{m,n}?`）或更精确的字符类。
- **永远用原始字符串**写正则，避免反斜杠灾难与 `\b` 冲突。
- 复杂正则可用 `re.VERBOSE` 标志开启注释与空白，让模式可读。

> 编者注：在 LLM 应用中，用正则**解析模型输出**时要保持防御性——模型可能返回意外格式，`re.search` 返回 `None` 是常态而非异常，务必判空再取 `group()`；更强的结构化抽取应该用 JSON mode / Pydantic 校验（见模块 5、第 10 篇），正则只做兜底。
