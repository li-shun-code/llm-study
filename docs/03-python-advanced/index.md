# 模块 3 · Python 进阶与框架

- 类型注解（typing）
- 正则表达式（re）
- requests
- httpx
- dataclasses 与 NamedTuple

- FastAPI 入门与 API Key 鉴权

- Docker 容器化
- Gradio
- Streamlit
- pytest 测试
- 日志 logging（logging.config）
- 性能分析（profile / cProfile / py-spy）
- uv / poetry 工程化
- 代码质量工具链（ruff / mypy / pre-commit）
