# 模块 7 · 数据库与向量存储

AI 应用的数据底座：SQL 与建模、PostgreSQL 工程化、缓存与文档存储，以及向量库的原理与选型。

## 学习路径

**SQL 与数据建模**

- 关系模型与 SQL 入门
- E-R 建模与范式：以"会话-消息"表设计为例
- SELECT 与增删改查（CRUD）
- 聚合与分组：GROUP BY、HAVING 与聚合函数
- JOIN 多表查询
- 索引原理与使用
- 事务与 ACID

**PostgreSQL 与工程化**

- PostgreSQL 入门

- PostgreSQL 全文检索（含中文分词）
- SQLAlchemy ORM 入门（2.0 风格，含连接池）

**缓存与文档型存储**

- Redis 核心数据结构与缓存
- Redis 语义缓存与 RediSearch（含向量检索）
- MongoDB 文档模型

**向量数据库**

- 向量数据库原理
- Chroma 与 Qdrant 单库实战
